# YouTube App Guide

## Navigation

- Bottom navigation bar has 5 tabs: **Home**, **Shorts**, a center **"+" (Create)** button, **Subscriptions**, and **You** (shows the user's profile avatar).
- Use these tabs to switch between the main sections of the app.

## Top Bar

- On the Home feed, the top bar shows: the YouTube logo (top-left), a notification bell icon, and a search icon (magnifying glass, top-right).
- Below the top bar is a horizontally scrollable row of filter chips (e.g. "All", "Hyped", "AI", "Podcasts", "News", with more available by scrolling further right). Tapping a chip filters the home feed by category — it does NOT open search.

## Common Tasks

- **To search for content** (songs, channels, videos, etc.): tap the search icon (magnifying glass, top-right of Home) → type the query → tap the search/submit action → results appear as a scrollable list. Do NOT type directly into the home feed — there is no direct text entry there.
- **To switch sections**: tap the corresponding bottom navigation tab (Home, Shorts, Create, Subscriptions, You).

## Watch Outs

- The Home feed is a vertically scrolling list of video cards that mixes organic recommendations with "Sponsored" ads. Sponsored cards carry a visible "Sponsored" label plus Watch/Install buttons — these are advertisements, not part of any task flow, and should not be tapped accidentally.
- Tapping a filter chip changes the feed content but does not navigate to a search screen — use the dedicated search icon for that instead.
